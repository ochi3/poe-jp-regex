# データ更新・確認・バックアップ

PoE1/PoE2の表示中のメインカード内の右上に、`Modデータ更新: 26/10/30 / 価格データ更新: 26/10/30` の形式で日付を常時表示します。JA/ENボタンも同じカード内にまとめています。

## 更新状況

`npm run build` は `data/status.json` にゲーム・Regexカテゴリ別のMod・価格の内容ハッシュを保存します。表示中のカテゴリに対応する日付へ自動で切り替わります。マップを更新しても装備・フラスコ等の日付は変わりません。スカラベの価格だけを更新しても、エッセンスなどの価格更新日は変わりません。価格だけの変更ではModの日時も変わりません。

カテゴリ別の記録は分離した初回のビルドから開始します。ACTはジェムデータとACTの生成コード、装備テキスト変換は変換エンジンを対象にします。実際のゲームパッチ公開日・価格取得日を保証する情報ではありません。

対応バージョンは管理者が `data/status.json` の各ゲームの `gameVersion` に登録し、補足は `versionNote` に記入できます。これらは更新日表示のツールチップで確認できます。価格が同じまま再取得された場合、検知日時は変わりません。

## プロファイル

「保存済みRegex」内のバックアップ欄から、このサイトの同一オリジンに保存されたPoE1/PoE2全カテゴリのプロファイルを1つのJSONに書き出せます。別のブラウザー・別ドメインの保存内容は直接読み取れません。

復元ファイルは全体を先に検証し、カテゴリ別件数を表示します。「確認した内容を追加で復元」で取り込みます。同名は「(復元 1)」などの別名にして元を残します。復元前の内容も保存し、バックアップ欄から書き出せます。失敗した場合は変更を戻します。正常終了後に「再読み込みして反映」を押してください。ファイルは10MB、合計5000プロファイルまでです。

## 選択中

マップ・海図・石板・装備・フラスコ・各カタログでは、リセットの左の「選択中（件数）」ボタンを押すとポップアップのリストが開きます。各項目の「解除」で1条件ずつ解除できます。元の一覧・Regex・保存状態も更新します。「閉じる」・Escape・枠外クリックで閉じられます。

## 公開前検査

`npm run check:release` は日英Regexの空欄・構文、JSON、日英接辞、HTML/TypeScriptの静的ファイル参照を検査します。メンテGUIの「コミット & push」の事前検査とGitHub Actionsにも組み込み、失敗時はpush前に停止します。ゲーム内での誤一致の全件検証は別途 `npm run regex:check` を使います。
